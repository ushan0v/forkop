# Сетевой интерфейс

Интерфейс OpenWrt, через который пойдёт трафик секции: основной или второй провайдер, LTE-модем или VPN, поднятый в самой OpenWrt. Несколько интерфейсов можно объединить в [Fallback](/connections/fallback), например основной провайдер и LTE на случай его падения.

## Что есть в списке

В списке провайдеры и туннели. Провайдеры — интерфейсы зоны `wan` и других зон файрвола с маскарадингом и интерфейсы с маршрутом по умолчанию, поэтому второй провайдер или LTE-модем появится в списке, когда его интерфейс в зоне `wan`. Туннели — WireGuard, AmneziaWG, OpenVPN, Tailscale, ZeroTier и другие.

В скобках рядом с устройством его интерфейсы OpenWrt, например `wan.30 (wan, wan6)`. У PPPoE в списке `pppoe-wan`, а не порт под ним, а пока соединение не поднято, это устройство отмечено отсутствующим. Порты LAN, мосты и Wi-Fi в список не входят, выхода в интернет через них нет. Другое устройство можно вписать вручную.

## Интерфейс или туннель Forkop

WireGuard, AmneziaWG и WARP Forkop умеет поднимать и сам, в поле [Туннель](/tunnels/). Разница в том, где работает туннель:

| | Интерфейс OpenWrt | Туннель Forkop |
| --- | --- | --- |
| Где работает | в ядре Linux | внутри sing-box |
| Нагрузка на роутер | обычно меньше памяти и процессора | больше, особенно на высокой скорости |
| Настройка | пакеты и **Сеть → Интерфейсы** | импорт профиля в окне секции |
| Обфускация WireGuard | только интерфейсом AmneziaWG | кнопкой **Сгенерировать параметры** |
| Каскад через другую секцию | нет | есть |

На слабом роутере или быстром канале выбирайте интерфейс. Туннель Forkop проще настроить.

## Как поднять WireGuard или AmneziaWG

1. Установите пакеты. Для WireGuard нужны `wireguard-tools` и `luci-proto-wireguard` из репозитория OpenWrt, для AmneziaWG `kmod-amneziawg`, `amneziawg-tools` и `luci-proto-amneziawg` из [awg-openwrt](https://github.com/Slava-Shchipunov/awg-openwrt). Затем перезагрузите роутер или выполните `service network restart`: новый протокол OpenWrt узнаёт только при перезапуске сети, а до этого интерфейс не поднимется.
2. В **Сеть → Интерфейсы** создайте интерфейс с протоколом WireGuard или AmneziaWG и загрузите конфигурацию.
3. У пира выключите **Маршрутизировать разрешённые IP-адреса**, иначе через туннель пойдёт весь трафик роутера.
4. Выберите интерфейс в поле **Сетевой интерфейс** секции.

## Резолвер доменов

С **Резолвером доменов** домены секции резолвят свои DNS-серверы интерфейса, а не общий DNS Forkop. Он нужен, когда за интерфейсом своя сеть со своими именами, например корпоративный VPN с внутренними доменами.

Серверы задаются в тех же [форматах](/dns/#форматы), что и основные, а несколько серверов страхуют друг друга, см. [DNS Fallback](/dns/#dns-fallback). Запросы резолвера идут через сам интерфейс, а **DNS через секцию** отправляет их через другую секцию.
