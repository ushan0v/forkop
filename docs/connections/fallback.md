# Fallback

Группа, которая держит первый рабочий сервер в заданном вами порядке. Пока главный сервер работает, трафик идёт через него. Если он упал, Fallback переходит на следующий, а когда главный вернётся, возвращается к нему.

## Группы серверов

Порядок задают группы серверов, их добавляет кнопка **Добавить серверы**. Fallback проверяет группы сверху вниз и берёт первый рабочий сервер из первой группы, где такой есть. Внутри группы он берёт первый рабочий сервер по порядку в секции, а не самый быстрый.

Какие серверы попадут в группу, решает её **Фильтр серверов**:

| Фильтр серверов | Что попадёт в группу |
| --- | --- |
| **Только выбранные** | серверы из **Включить серверы** и **Включить по шаблону** |
| **Кроме выбранных** | все оставшиеся серверы, кроме исключённых |
| **Все оставшиеся** | все серверы, которых нет в группах выше |
| **Напрямую** | выход без VPN, через провайдера |

Поля фильтра те же, что в [фильтре подписки](/connections/subscriptions#фильтр-серверов).

Сервер попадает только в первую подходящую группу, а серверы вне групп Fallback не использует. Поэтому последней обычно ставят **Все оставшиеся**.

Например, свой сервер главный, а подписка в запасе:

1. Группа «Мой сервер», **Только выбранные**, в **Включить серверы** ваш сервер.
2. Группа «Подписка», **Все оставшиеся**.

## Fallback и URLTest вместе

Чтобы в группе работал самый быстрый сервер, создайте URLTest и выберите его в поле **Добавить URLTest** у группы. URLTest участвует в группе как один сервер, тот, который выбрал сам. Он стоит в группе первым, а её остальные серверы работают, только если он не ответил. Секция с таким Fallback работает через Fallback, а не через URLTest отдельно.

## Как выбирается сервер

Раз в **Интервал проверки** Fallback проверяет серверы. Если соединение через сервер не установилось за **Таймаут подключения**, Fallback сразу пробует следующий. Если не прошла ни одна проверка, он всё равно пробует первый сервер.

| Параметр | По умолчанию | Что задаёт |
| --- | --- | --- |
| **URL проверки** | `https://www.gstatic.com/generate_204` | адрес для проверки доступности |
| **Интервал проверки** | `5m` | как часто проверять серверы |
| **Таймаут проверки** | `5s` | сколько ждать ответа на проверке |
| **Таймаут подключения** | `5s` | сколько ждать соединения, прежде чем перейти к следующему серверу |
| **Ожидаемый статус** | `*` | какие HTTP-коды считать успехом |
| **Таймаут простоя** | `5m` | через сколько остановить проверки, если через Fallback ничего не идёт |
| **Прерывать соединения** | выключено | закрывать открытые соединения при переходе на другой сервер. Включите, если после переключения старые соединения зависают на упавшем сервере |

Кнопка ⓘ на карточке Fallback на вкладке **Дашборд** показывает, какой сервер выбран сейчас и в какую группу попал каждый сервер. Щелчок по серверу там закрепляет его, повторный открепляет. Закрепление снимается, когда сервер не прошёл проверку, а другой прошёл.
