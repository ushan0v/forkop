# URLTest

Группа, которая держит самый быстрый рабочий сервер секции. В неё попадают серверы этой секции, а какие именно, решает **Фильтр серверов**, устроенный так же, как [фильтр подписки](/connections/subscriptions#фильтр-серверов).

## Как выбирается сервер

Раз в **Интервал проверки** группа замеряет задержку каждого сервера и держит сервер, который медленнее самого быстрого не больше чем на **Разницу задержки**. Так она не переключается из-за пары миллисекунд, поэтому выбранный сервер не всегда с самой маленькой задержкой. Если соединения через выбранный сервер начинают падать, группа проверяет серверы сразу, не дожидаясь интервала.

| Параметр | По умолчанию | Что задаёт |
| --- | --- | --- |
| **URL проверки** | `https://www.gstatic.com/generate_204` | адрес для замера задержки |
| **Интервал проверки** | `3m` | как часто проверять серверы |
| **Разница задержки** | `50` | на сколько миллисекунд выбранный сервер может быть медленнее самого быстрого |
| **Ожидаемый статус** | `*` | какие HTTP-коды считать успехом, например `204/200-299`. `*` значит любой ответ |
| **Таймаут простоя** | `30m` | через сколько остановить проверки, если через группу ничего не идёт |
| **Прерывать соединения** | выключено | закрывать открытые соединения при переходе на другой сервер. Включите, если после переключения старые соединения зависают на упавшем сервере |

Какие серверы попали в группу и какой выбран сейчас, показывает кнопка ⓘ на карточке группы на вкладке **Дашборд**.

## URLTest или Fallback

URLTest смотрит только на скорость. Если серверы не равноценны, например свой сервер и запасная подписка, или нужен строгий порядок переключения, используйте [Fallback](/connections/fallback).
