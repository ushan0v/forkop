# Cloudflare WARP

Бесплатный VPN Cloudflare без своего сервера. Через него работают YouTube, Discord и сайты, которые блокирует РКН.

Cloudflare выдаёт адрес страны, из которой к нему подключились. Поэтому сервисы, закрытые для России, например ChatGPT и Gemini, через WARP не откроются. Для них нужен [WARP в другой стране](#warp-в-другои-стране).

## Создать туннель

1. Секция → **Добавить туннель** → **Тип туннеля**: **Cloudflare WARP**.
2. Нажмите **Сгенерировать профиль**.
3. Включите **Обфускацию трафика**, нажмите **Сгенерировать параметры**.

Без обфускации провайдеры в России режут WARP. Регистрация и профиль идут через `api.devices.cloudflare.com`. Если **Сгенерировать профиль** не срабатывает, включите в настройках **Запрашивать WARP через секцию** и выберите секцию с рабочим подключением. Трафик туннеля всё так же пойдёт напрямую или через каскад из его настроек.

Если у вас есть WARP+, впишите ключ из приложения 1.1.1.1 в поле **Лицензионный ключ**.

## WARP в другой стране

Включите у туннеля **Каскадное подключение** через секцию с сервером в нужной стране. Cloudflare выдаст WARP адрес этой страны, например каскад через сервер во Франции даёт WARP Франции.
